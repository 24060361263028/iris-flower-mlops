1. WHAT IS THIS PROJECT ABOUT?
--------------------------------------------------------------------------------
The goal of this project is to build an artificial intelligence system that can
look at four measurements of an Iris flower and instantly identify which
species (type) of Iris flower it is.

The 4 Inputs (measurements in centimeters):
  1. Sepal Length  (cm)
  2. Sepal Width   (cm)
  3. Petal Length  (cm)
  4. Petal Width   (cm)

The 3 Possible Outputs (the flower species):
  1. Setosa
  2. Versicolor
  3. Virginica

The Dataset:
  - Contains exactly 150 flower observations:
    * 50 Setosa flowers
    * 50 Versicolor flowers
    * 50 Virginica flowers
  - It is built directly into scikit-learn, so no external download is needed.

The Machine Learning Algorithm:
  - Random Forest Classifier (A collection of decision trees that vote together
    to give the most accurate flower classification).

2. SIMPLE EXPLANATION OF ALL MLOPS TOOLS USED
--------------------------------------------------------------------------------
MLOps means "Machine Learning Operations". It is the set of tools used by top
tech companies to take machine learning models from a test script and run them
reliably in real life.

Here is what each tool in your project does:

1. GIT
   - Purpose: Code Version Control.
   - What it does: Keeps a history of every file and change made in the project,
     so nothing is ever lost.

2. DVC (Data Version Control)
   - Purpose: Data and Pipeline Automation.
   - What it does: Manages data files and runs the 3-step pipeline automatically
     (Prepare Data -> Train Model -> Evaluate Performance).

3. SCIKIT-LEARN
   - Purpose: Machine Learning Library.
   - What it does: Provides the Iris dataset, trains the Random Forest model,
     and calculates accuracy scores.

4. MLFLOW
   - Purpose: Experiment Tracking.
   - What it does: Records every training run, saves the model settings
     (hyperparameters), and logs the accuracy and metrics to a visual dashboard.

5. PYTEST
   - Purpose: Automated Testing.
   - What it does: Runs 16 automated tests to ensure the data is complete,
     the model is over 90% accurate, and the website API responds correctly.

6. FASTAPI
   - Purpose: Web Service (API).
   - What it does: Provides a fast, live web server where any app or website
     can send 4 numbers and receive back the predicted flower species.

7. DOCKER
   - Purpose: Containerization.
   - What it does: Packages the entire project, Python, and all libraries into a
     lightweight container that can run on any server without installing anything.

8. GITHUB ACTIONS
   - Purpose: Continuous Integration (CI/CD).
   - What it does: Automatically tests your code and builds the Docker container
     every time changes are pushed to GitHub.

4. HOW TO RUN AND OPEN EVERYTHING (EASY STEP-BY-STEP)
--------------------------------------------------------------------------------

Option A: Open the Desktop App (GUI with Sliders & Buttons)
----------------------------------------------------------
1. Open PowerShell.
2. Run this command:
     cd d:\mloops
     .\.venv\Scripts\python.exe gui_app.py
3. A friendly window will appear on your screen with sliders.
4. Move the sliders or click sample buttons (Setosa, Versicolor, Virginica),
   then click "Classify Iris Species" to see instant predictions.


Option B: Open the Web API in Your Browser (Swagger UI)
-------------------------------------------------------
1. Open PowerShell and start the server:
     cd d:\mloops
     .\.venv\Scripts\uvicorn.exe app.main:app --host 127.0.0.1 --port 8000 --reload
2. Open your web browser and go to:
     http://127.0.0.1:8000/docs
3. Click "POST /predict", click "Try it out", and click "Execute" to test.


Option C: Open the MLflow Dashboard (Graphs & Metrics)
------------------------------------------------------
1. Open PowerShell and run:
     cd d:\mloops
     .\.venv\Scripts\mlflow.exe ui --host 127.0.0.1 --port 5000
2. Open your browser and go to:
     http://127.0.0.1:5000
3. Click "Iris_Flower_Classification" on the left to see your training runs.


Option D: Run the Full DVC Pipeline
-----------------------------------
To run the automated data split, model training, and evaluation in one step:
     cd d:\mloops
     dvc repro
To see the accuracy table:
     dvc metrics show


Option E: Run All 16 Automated Tests
------------------------------------
To run the pytest suite:
     cd d:\mloops
     pytest -v
